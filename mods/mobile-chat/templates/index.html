生成设置

本页先承接 v0.1 已有设置。v1.0 后续会继续拆分模型、prompt 和自动行为。

群聊管理

编辑群名、简介、成员、回复人数和自动插话开关。群聊仍独立保存在 data/mobile_chat。

角色管理

维护小手机自己的角色资料库。这里的资料只影响小手机 prompt，不会写回角色卡。

表情包管理

读取本地 PNG，并可编辑对应 manifest.json 的 label、tags 和 description。PNG 资源本身不进入 PR。

自动行为

默认关闭。开启后由前台页面在空闲时调用小手机自己的续聊接口，带有频率限制和多标签锁。

Prompt 配置

这里管理小手机自己的 prompt blocks 和输出契约。默认不影响正文，也不写回角色卡。
