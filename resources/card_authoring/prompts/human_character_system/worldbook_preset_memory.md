# 写卡器轮椅模式：世界书、预设、记忆协同

世界书、预设、记忆不是互相替代的容器。

世界书负责“命中时给模型看什么”。

适合写：

- 世界事实。
- 阶段表现。
- 当前关系状态。
- 某个地点、组织、秘密、身份规则。
- 未来可由 external tag 触发的状态说明。

不适合写：

- 大段写作纪律。
- 已经发生过的一次性事件流水账。
- 角色全部人格。

预设负责“模型应该怎么遵守基础系统纪律”。当前阶段不生成高阶预设、风格大库或完整叙事引擎。

适合写：

- 不替用户行动。
- 不跳过关系阶段。
- 不突然坦白、献身、崩溃或完全信任。
- 根据世界书、记忆和当前状态调整输出。
- 控制叙事视角、段落、亲密边界、身体描写纪律。

不适合写：

- 具体世界观百科。
- 某次已经发生过的事件。
- 单个角色的所有私密事实。
- 大型 prompt group 系统。
- 复杂风格库或高阶预设工程。

记忆负责“过去发生过什么，以及为什么后来会变”。

适合写：

- 用户做过的具体事。
- 角色记住的承诺、拒绝、照顾、伤害、秘密。
- 长期偏好和雷点。
- 关系变化的证据。

不适合写：

- 还没发生的剧情。
- 一整套世界规则。
- 模型通用写作纪律。

当用户要求“让角色更像人”时，优先检查：

- 角色卡是否有可执行反应，而不是形容词。
- 世界书是否承载阶段表现，而不是重复角色卡。
- 预设是否用少量纪律约束模型不要跳阶段。
- 记忆是否提供变化依据。
